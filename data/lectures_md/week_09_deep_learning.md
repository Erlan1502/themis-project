## Практический пример 2. CNN и распознавание рукописных цифр (MNIST)
В отличие от MLP, свёрточная сеть обрабатывает локальные области изображения.
- `Conv2D` извлекает локальные признаки с помощью обучаемых фильтров.
- `MaxPooling2D` уменьшает пространственный размер карт признаков.
- `Flatten` преобразует карты признаков в вектор для полносвязных слоёв.
- `Softmax` выдаёт распределение вероятностей по десяти классам.

Ниже пример посложнее: три блока Conv2D + MaxPooling2D, функция активации GELU, BatchNormalization и Dropout. Перед запуском включите GPU (Runtime → Change runtime type → T4 GPU).

```python
import tensorflow as tf
from tensorflow.keras.datasets import mnist
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Conv2D, MaxPooling2D, Dense, Flatten, Dropout, BatchNormalization

# 1. Загружаем датасет рукописных цифр MNIST
(x_train, y_train), (x_test, y_test) = mnist.load_data()

# 2. Нормализация и изменение формы (28x28 → 28x28x1)
x_train = x_train.astype("float32") / 255.0
x_test  = x_test.astype("float32") / 255.0

x_train = x_train[..., tf.newaxis]   # (60000, 28, 28, 1)
x_test  = x_test[..., tf.newaxis]    # (10000, 28, 28, 1)

# 3. Модель: несколько Conv2D + MaxPool + GELU + плотные слои
model = Sequential([
    tf.keras.Input(shape=(28, 28, 1)),
    # Блок 1: Conv + MaxPool
    Conv2D(32, (3, 3), activation=tf.keras.activations.gelu,
           padding='same'),
    MaxPooling2D((2, 2)),
    BatchNormalization(),

    # Блок 2: Conv + MaxPool
    Conv2D(64, (3, 3), activation=tf.keras.activations.gelu,
           padding='same'),
    MaxPooling2D((2, 2)),
    BatchNormalization(),

    # Блок 3: Conv + MaxPool
    Conv2D(128, (3, 3), activation=tf.keras.activations.gelu,
           padding='same'),
    MaxPooling2D((2, 2)),
    BatchNormalization(),

    # Переход к полносвязным слоям
    Flatten(),
    Dense(256, activation=tf.keras.activations.gelu),
    Dropout(0.5),
    Dense(10, activation='softmax')  # 10 классов (цифры 0–9)
])

# 4. Компиляция модели
model.compile(optimizer='adam',
              loss='sparse_categorical_crossentropy',
              metrics=['accuracy'])

# 5. Обучение
history = model.fit(
    x_train, y_train,
    epochs=3,          # на лекции 3 эпохи (~1 мин на GPU); на CPU одна эпоха ~2–3 мин
    batch_size=64,
    validation_split=0.2
)

# 6. Оценка
test_loss, test_acc = model.evaluate(x_test, y_test)
print(f"Точность на тестовых данных: {test_acc:.4f}")
```

- Modified National Institute of Standards and Technology (MNIST) — модифицированная база данных рукописных цифр.

- Несмотря на то что MNIST хорошо “работает” для обучения моделей, его ограниченная сложность означает, что успех на MNIST не гарантирует успех на более реалистичных или сложных задачах.

- **GELU (Gaussian Error Linear Unit)** — это современная функция активации в нейронных сетях, которая сочетает преимущества ReLU и Sigmoid, обеспечивая более плавное и точное обучение.

### Слайд 2
- Что такое нейронная сеть?
- Нейронная сеть — это вычислительная модель, созданная по аналогии со строением и работой человеческого мозга.
- Она состоит из слоёв искусственных нейронов (узлов), которые обрабатывают входные данные и учатся принимать решения или делать прогнозы.
- Каждый нейрон получает входы, вычисляет взвешенную сумму, пропускает её через функцию активации и передаёт результат следующему слою.
- Ключевая идея:
- Нейронные сети учатся закономерностям на данных, а не программируются явными правилами.

- Обнаружение мошенничества и аномалий
- Беспилотные автомобили
- Медицинская диагностика

### Слайд 11
- Функции активации: ReLU и сигмоида
- ReLU имеет несколько преимуществ по сравнению с сигмоидой. Во-первых, она вычислительно эффективнее: это простая операция max(0, x) без экспоненты. Во-вторых, ReLU смягчает проблему затухания градиента: при x > 0 её производная равна 1, поэтому градиент не уменьшается, как у сигмоиды (её производная не больше 0,25).
- Однако у ReLU есть недостатки. Во-первых, нейроны могут «умереть» (dying ReLU): если взвешенная сумма на входе нейрона почти всегда отрицательна, он всегда выдаёт 0, градиент через него тоже 0, и его веса перестают обновляться. Во-вторых, выходы ReLU не центрированы относительно нуля (только ≥ 0), что может замедлять сходимость. Для смягчения этих проблем используют Leaky ReLU, ELU, GELU.

### Слайд 12
- Функция активации Leaky ReLU
- где α — наклон при отрицательных x, небольшое положительное число, например 0,01.
- Leaky ReLU сохраняет небольшой градиент при x < 0, поэтому нейроны не «умирают». Это может ускорить сходимость, но выигрыш по сравнению с ReLU не гарантирован: варианты стоит сравнивать на валидационной выборке.

### Слайд 13
- Функция активации: гиперболический тангенс
- Переводит входные значения в диапазон от −1 до 1.
- Выход центрирован относительно нуля (в отличие от сигмоиды), поэтому tanh часто используют в скрытых слоях и в ячейках RNN/LSTM. При больших |x| функция насыщается, и градиент затухает, как у сигмоиды.

### Слайд 14
- Функция активации Softmax
- Softmax превращает вектор чисел в распределение вероятностей с суммой 1. Используется на выходе многоклассового классификатора, чтобы получить вероятность каждого класса.
- где z_i — i-й элемент входного вектора (логит), k — число классов; в знаменателе сумма e^{z_j} по всем j = 1…k.

### Слайд 15
- Как выбрать функцию активации?
- Выбор зависит от того, скрытый это слой или выходной, и от типа задачи:
- Скрытые слои: ReLU по умолчанию (или Leaky ReLU, ELU, GELU).
- Выходной слой, бинарная классификация: 1 нейрон + Sigmoid (вероятность класса «1»).
- Выходной слой, многоклассовая классификация: K нейронов + Softmax (сумма вероятностей = 1). Если у объекта может быть несколько меток сразу (multi-label), то Sigmoid на каждый выход.
- Выходной слой, регрессия: линейный выход без активации (ReLU на выходе только если ответ заведомо ≥ 0).

### Слайд 16
- Как выбрать функцию активации?
- Для глубоких сетей ReLU — стандартный выбор в скрытых слоях, так как ускоряет обучение; также используют PReLU, Swish, GELU.
- В рекуррентных сетях (RNN, LSTM) внутри ячеек обычно используются tanh и sigmoid.
- Если не уверены, попробуйте несколько функций активации и сравните результат на валидационной выборке.
- При выборе учитывайте свойства функции: производную, нелинейность и устойчивость к затуханию градиента.

### Слайд 17
- Процесс обучения сети
- Обучение — это подбор весов и смещений, при котором ошибка предсказания становится минимальной.
- Шаги:
- Прямое распространение (forward) — вычисляем выход сети для входа.
- Вычисление ошибки (loss) — измеряем разницу между предсказанием и правильным ответом.
- Обратное распространение (backpropagation) — вычисляем градиенты ошибки по каждому весу.
- Обновление весов — шаг градиентного спуска или его вариантов.

### Слайд 18
- 1. Прямое распространение (forward)
- • На вход подаются данные x.
- • Каждый нейрон вычисляет взвешенную сумму входов:
- • Результат проходит через функцию активации, например ReLU или Sigmoid.
- • На выходе сеть выдаёт предсказание ŷ.
- Пример: сеть предсказала вероятность рака груди ŷ = 0,85,
- а правильный ответ y = 1 (истина).

### Слайд 19
- 2. Вычисление ошибки (loss)
- • Функция потерь (например, binary cross-entropy) измеряет, насколько предсказание ошибочно:
- • Для примера: ŷ = 0,85, y = 1 → L = −ln 0,85 ≈ 0,16 (ошибка небольшая).
- • Если бы ŷ = 0,10 → L = −ln 0,10 ≈ 2,30: уверенная ошибка штрафуется сильно.
- • Чем больше ошибка, тем сильнее нужно поправить веса.

### Слайд 22
- Цикл обучения
- • Эти четыре шага повторяются для каждой партии данных (batch) на каждой эпохе:
- Forward  →  Loss  →  Backpropagation  →  Update weights

- • и сеть учится распознавать закономерности в данных.

### Слайд 23
- Интуитивная аналогия
- Представьте, что вы бросаете мяч в корзину:
- Forward: бросаете мяч (делаете предсказание).
- Loss: смотрите, насколько промахнулись.
- Backpropagation: анализируете ошибку: куда подправить движение руки.
- Weight update: корректируете бросок (меняете параметры).
- Повторяете много раз — и меткость постепенно растёт 🎯

### Слайд 24
- Эпоха, batch и итерация
- • Эпоха (epoch) — один полный проход по всей обучающей выборке.
- • Batch — порция примеров, после которой делается один шаг обновления весов.
- • Итерация — один шаг: forward → loss → backward → update на одном batch.
- • Пример: 60 000 картинок, batch = 64 → 938 итераций за эпоху; 10 эпох → 9 380 обновлений весов.
- • Мало эпох → недообучение; слишком много → переобучение (loss на validation начинает расти).
- • Маленький batch: шумные, но частые шаги; большой batch: быстрее на GPU, нужно больше памяти. Типично 32–256.
