**1.2. Программная реализация математического ядра
(**themis_math_engine.py**)**

Ниже представлен готовый к интеграции в продакшен и полностью
детерминированный Python-модуль математического ядра **Themis Project
v2.0**, реализующий все исправленные формулы, фильтрацию случайных
входов, одностороннюю положительную ректификацию и генерацию
канонического датасета для демонстрации.

```python
"""

themis_math_engine.py

Детерминированное психометрическое и статистическое ядро системы Themis
Project (v2.0).

Реализует:

1. Прогрессивную свертку вероятностей таксономии SOLO по шагам диалога.

2. Вогнутую корневую калибровку S_SOLO и формализованный бонус
сократической инициативы.

3. Защищенный от штрафов за развернутую речь коэффициент плотности
концептов K_density.

4. Одностороннюю положительную ректификацию дельты (Delta_pos = max(0,
S_depth - G_prof)).

5. Байесовски регуляризованный робастный Z-score с защитой от Selection
Bias и деления на ноль.

"""

from dataclasses import dataclass, asdict

from typing import List, Dict, Optional, Tuple

import math

import numpy as np

from pydantic import BaseModel, Field, field_validator

# =====================================================================

# 1. PYDANTIC-СХЕМЫ КАЛИБРОВАННОЙ ЭКСТРАКЦИИ (EVIDENCE-FIRST PROTOCOL)

# =====================================================================

class TurnSOLOProbabilities(BaseModel):

"""Распределение вероятностей по уровням SOLO для одного шага
диалога."""

turn_number: int = Field(..., ge=1, description="Номер реплики студента
в диалоге")

p1: float = Field(..., ge=0.0, le=1.0, description="Surface /
Multistructural")

p2: float = Field(..., ge=0.0, le=1.0, description="Relational
(механизмы и связи)")

p3: float = Field(..., ge=0.0, le=1.0, description="Extended Abstract
(компромиссы и синтез)")

def normalized_Tuple(self) -> Tuple[float, float, float]:

total = self.p1 + self.p2 + self.p3

if total <= 1e-9:

return (1.0, 0.0, 0.0)

return (self.p1 / total, self.p2 / total, self.p3 / total)

class AuditExtractionResult(BaseModel):

"""

Строгая схема ответа LLM-экстрактора (Qwen3.5-27B / Qwen3.5-9B).

Порядок полей критичен (Evidence-First): модель сначала извлекает цитаты

и концепты, и только в конце вычисляет вероятности SOLO.

"""

on_topic: bool = Field(..., description="True, если ответы студента
относятся к теме лекции")

student_quotes: List[str] = Field(..., description="Прямые цитаты
студента, доказывающие глубину понимания")

mastered_concepts: List[str] = Field(..., description="Освоенные
доменные концепты из глоссария занятия")

socratic_initiative: bool = Field(

default=False,

description="True, если студент самостоятельно сформулировал
исследовательский вопрос/гипотезу 3-го уровня"

)

pedagogical_justification: str = Field(..., description="Краткое
аналитическое обоснование для преподавателя")

turns_probabilities: List[TurnSOLOProbabilities] = Field(

..., description="Оценка вероятностей SOLO по каждому шагу диалога"

)

# =====================================================================

# 2. СТРУКТУРЫ ДАННЫХ АУДИТА СТУДЕНТА И ПОТОКА

# =====================================================================

@dataclass

class StudentAuditRecord:

student_id: str

in_class_grade: Optional[float] # Очная оценка преподавателя G_prof
(неприкосновенна)

session_status: str # OPTED_OUT | INCOMPLETE_IGNORED | COMPLETED

turns_count: int

total_tokens: int

extraction: Optional[AuditExtractionResult] = None

# Вычисляемые диагностические метрики (не являются зачетными и не
суммируются с G_prof)

agg_probabilities: Tuple[float, float, float] = (0.0, 0.0, 0.0)

e_d_squared: float = 1.0

s_solo: float = 0.0

k_density: float = 0.0

c_sample: float = 0.0

ai_depth_score: Optional[float] = None # Диагностический индекс
глубины S_depth

raw_delta: Optional[float] = None # Сырая разница S_depth - G_prof
(для оценки шума канала)

rectified_delta: float = 0.0 # Положительная ректификация max(0.0,
S_depth - G_prof)

z_score: float = 0.0 # Односторонний робастный Z-score

zone: str = "NO_SIGNAL" # NO_SIGNAL | NORMAL | WATCHLIST |
AUDIT_TRIGGER | HIGH_DISCREPANCY

# =====================================================================

# 3. ЯДРО МАТЕМАТИЧЕСКОГО АУДИТА THEMIS ENGINE V2.0

# =====================================================================

class ThemisMathEngine:

"""Детерминированный вычислитель диагностических метрик Themis
Project."""

# Канонические веса прогрессивной свертки для 3-шагового сократического
диалога

CANONICAL_3TURN_WEIGHTS = (0.0556, 0.1320, 0.8124)

def __init__(

self,

target_turns: int = 3,

density_alpha: float = 3.5,

density_floor: float = 0.75,

initiative_bonus: float = 1.0,

sigma_min: float = 4.0,

prior_weight_n: int = 10,

use_bayesian_shrinkage: bool = False,

):

self.target_turns = target_turns

self.density_alpha = density_alpha

self.density_floor = density_floor

self.initiative_bonus = initiative_bonus

self.sigma_min = sigma_min

self.prior_weight_n = prior_weight_n

self.use_bayesian_shrinkage = use_bayesian_shrinkage

def aggregate_turn_probabilities(

self, turns: List[TurnSOLOProbabilities]

) -> Tuple[float, float, float]:

"""

Прогрессивная свертка вероятностей по шагам диалога.

Устраняет штраф за простые ответы на стартовый разогревочный вопрос
бота.

"""

if not turns:

return (1.0, 0.0, 0.0)

n = len(turns)

if n == 3:

weights = np.array(self.CANONICAL_3TURN_WEIGHTS, dtype=float)

else:

# Экспоненциальное взвешивание для произвольного числа реплик

gamma = 1.35

t_idx = np.arange(1, n + 1, dtype=float)

weights = np.exp(gamma * t_idx)

weights /= np.sum(weights)

p_matrix = np.array([t.normalized_Tuple() for t in turns],
dtype=float)

p_agg = weights @ p_matrix

p_agg = np.round(p_agg, 2)

# Точная нормировка суммы до 1.0 после округления

diff = round(1.0 - float(np.sum(p_agg)), 2)

p_agg[2] = round(float(p_agg[2]) + diff, 2)

return (float(p_agg[0]), float(p_agg[1]), float(p_agg[2]))

def compute_individual_depth(self, record: StudentAuditRecord) ->
StudentAuditRecord:

"""

Этап 3A: Вычисление диагностического скора S_depth для отдельного
студента.

Если студент не пользовался ботом или зашел случайно (N_turns < 2),

диагностический сигнал не формируется, очная оценка преподавателя
неприкосновенна.

"""

if (

record.session_status != "COMPLETED"

or record.turns_count < 2

or record.extraction is None

or not record.extraction.on_topic

):

record.ai_depth_score = None

record.zone = "NO_SIGNAL"

return record

# 1. Агрегация вероятностей SOLO по шагам диалога

p1, p2, p3 =
self.aggregate_turn_probabilities(record.extraction.turns_probabilities)

record.agg_probabilities = (p1, p2, p3)

# 2. Математическое ожидание квадратичного веса E[D^2] in [1.0,
9.0]

e_d2 = 1.0 * p1 + 4.0 * p2 + 9.0 * p3

record.e_d_squared = round(e_d2, 2)

# 3. Корневая калибровка S_SOLO + формализованный бонус за
сократическую инициативу

base_solo = 100.0 * math.sqrt(max(0.0, (e_d2 - 1.0) / 8.0))

init_bonus = self.initiative_bonus if
record.extraction.socratic_initiative else 0.0

record.s_solo = round(min(100.0, base_solo + init_bonus), 1)

# 4. Калиброванный коэффициент семантической плотности K_density

n_concepts = len(record.extraction.mastered_concepts)

raw_density = (self.density_alpha * n_concepts) / math.sqrt(max(1,
record.total_tokens))

record.k_density = round(min(1.0, max(self.density_floor, raw_density)),
3)

# 5. Порог уверенности выборки C_sample

record.c_sample = round(min(1.0, record.turns_count /
float(self.target_turns)), 2)

# 6. Итоговый диагностический индекс глубины S_depth

record.ai_depth_score = round(record.s_solo * record.k_density *
record.c_sample, 1)

return record

def compute_cohort_discrepancy(

self, records: List[StudentAuditRecord]

) -> Dict[str, object]:

"""

Этап 3B: Реактивный расчет односторонней положительной ректификации
Delta_pos

и робастного Z-score по группе.

Правило Themis Project: если оценка преподавателя выше (S_depth <=
G_prof),

занижение НЕ рассматривается (rectified_delta = 0.0, статус NORMAL).

"""

valid_raw_deltas: List[float] = []

for r in records:

self.compute_individual_depth(r)

if r.ai_depth_score is not None and r.in_class_grade is not None:

raw_d = round(r.ai_depth_score - r.in_class_grade, 1)

r.raw_delta = raw_d

# Односторонняя положительная ректификация: занижение никогда не
рассматривается

r.rectified_delta = round(max(0.0, raw_d), 1)

valid_raw_deltas.append(raw_d)

else:

r.raw_delta = None

r.rectified_delta = 0.0

if not valid_raw_deltas:

return {

"median_delta": 0.0,

"mad": 0.0,

"robust_sigma": self.sigma_min,

"sigma_thresholds": {"plus_1_sigma": 4.0, "plus_2_sigma": 8.0,
"plus_3_sigma": 12.0},

"alerts_count": {"green": 0, "yellow": 0, "red": 0, "purple": 0},

}

arr = np.array(valid_raw_deltas, dtype=float)

raw_median = float(np.median(arr))

mad = float(np.median(np.abs(arr - raw_median)))

# Опциональное байесовское сжатие медианы к априорному нулю при сильном
перекосе выборки

if self.use_bayesian_shrinkage:

n_val = len(arr)

center_median = (n_val / (n_val + self.prior_weight_n)) * raw_median

else:

center_median = raw_median

# Защита знаменателя от деления на ноль (MAD = 0)

robust_sigma = max(self.sigma_min, 1.4826 * mad)

alerts_count = {"green": 0, "yellow": 0, "red": 0, "purple": 0}

for r in records:

if r.raw_delta is None:

r.zone = "NO_SIGNAL"

r.z_score = 0.0

continue

# Если оценка преподавателя выше или равна ИИ — полное согласие, ноль
вмешательства

if r.rectified_delta <= 0.0:

r.z_score = 0.0

r.zone = "NORMAL"

alerts_count["green"] += 1

continue

z_val = (r.rectified_delta - center_median) / robust_sigma

r.z_score = round(z_val, 2)

# Классификация положительных аномалий (Undergrading Detection)

if r.z_score >= 3.0 and r.rectified_delta >= 20.0:

r.zone = "HIGH_DISCREPANCY"

alerts_count["purple"] += 1

elif r.z_score >= 2.0 and r.rectified_delta >= 15.0:

r.zone = "AUDIT_TRIGGER"

alerts_count["red"] += 1

elif r.z_score >= 1.0 and r.rectified_delta >= 10.0:

r.zone = "WATCHLIST"

alerts_count["yellow"] += 1

else:

r.zone = "NORMAL"

alerts_count["green"] += 1

return {

"median_delta": round(center_median, 2),

"mad": round(mad, 2),

"robust_sigma": round(robust_sigma, 2),

"sigma_thresholds": {

"plus_1_sigma": round(center_median + 1.0 * robust_sigma, 2),
```

**Проблема: Vocal Confidence Bias и институциональный Undergrading**

Традиционный компонент оценки за работу на занятии (Classroom
Participation Mark) страдает когнитивным искажением — «эффектом ореола»
(Halo Effect):

- Преподаватель непроизвольно приравнивает беглую, громкую речь и
  быструю реакцию к глубокому пониманию дисциплины.

- Перспективные студенты, испытывающие языковой барьер, тревожность
  перед публичным ответом у доски или потребность в когнитивной паузе
  для построения сложной мысли, систематически получают заниженные баллы
  (\$60\text{–}70\$ из \$100\$), хотя их реальное владение материалом
  находится на уровне \$90+\$.

**Три фундаментальных принципа «Цифрового пандуса» (Themis
Constitutional Rules)**

В парадигме Universal Design for Learning (UDL) **Themis Project**
работает по трем нерушимым правилам:

1.  **Полная добровольность (Принцип пандуса / Optional Affordance):**
    Приложение открыто для каждого студента группы, но не является
    обязательным. Если студент уверенно ответил на паре или просто не
    желает пользоваться ботом, это **никак не влияет на его оценку** — в
    силе остается оценка, выставленная преподавателем.

2.  **Некредитный диагностический статус (Non-Credit Diagnostic
    Signal):** Внутренний скор глубины ИИ (\$S\_{\text{depth}}\$) **не
    является зачетной оценкой**, не идет в ведомость и никак не
    суммируется и не усредняется с оценками преподавателя. Его
    единственная цель — выявить перспективных студентов, чьи знания
    оказались скрыто недооценены (Undergraded) на очном занятии, и
    предоставить преподавателю доказательный аналитический отчет (AI
    Discrepancy Report) с прямыми цитатами для возможного пересмотра
    балла.

3.  **Односторонняя положительная ректификация (Zero Downward
    Penalty):** Система ищет исключительно положительные расхождения
    (\$S\_{\text{depth}} \> G\_{\text{prof}}\$). В обратной ситуации —
    когда оценка преподавателя выше скора ИИ (\$G\_{\text{prof}} \ge
    S\_{\text{depth}}\$) — **занижение оценки категорически не
    рассматривается**: студент мог зайти в приложение случайно,
    посмотреть интерфейс и закрыть вкладку. Любое отрицательное
    отклонение автоматически ректифицируется в ноль (\$\Delta_i^+ =
    0\$).

**4. Математический аппарат и психометрические формулы (v2.0)**

**4.1. Пошаговая оценка SOLO и прогрессивная сократическая свертка**

На каждом шаге диалога \$t \in \\1, \dots, N\_{\text{turns}}\\\$
модель-аудитор (после извлечения текстовых цитат и концептов по
протоколу *Evidence-First*) формирует вектор вероятностей по таксономии
Биггса (SOLO):

\$\$\mathbf{P}\_t = \[p\_{1,t}, p\_{2,t}, p\_{3,t}\], \quad
\sum\_{k=1}^3 p\_{k,t} = 1\$\$

- \$p_1\$ (*Surface / Multistructural*) — воспроизведение определений,
  базовых фактов.

- \$p_2\$ (*Relational*) — объяснение причинно-следственных связей,
  архитектурных механизмов.

- \$p_3\$ (*Extended Abstract*) — системный синтез, анализ компромиссов
  (trade-offs) и поведения на границах применимости (edge cases).

Поскольку сократический диалог строится от простого к сложному (Шаг 1 —
разогрев и определения, Шаг 2 — механизмы, Шаг 3 — граничные условия),
применяется **прогрессивная экспоненциальная свертка шагов** с
каноническими весами для трехшаговой сессии \$\mathbf{w} = \[0.0556,
0.1320, 0.8124\]\$:

\$\$\mathbf{P}\_{\text{agg}} = \[p_1, p_2, p_3\] =
\sum\_{t=1}^{N\_{\text{turns}}} w_t \mathbf{P}\_t\$\$

**4.2. Квадратичное ожидание \$\mathbb{E}\[D^2\]\$ и корневая калибровка
\$S\_{\text{SOLO}}\$**

Вычисляется математическое ожидание квадратичного веса когнитивной
сложности: \$\$\mathbb{E}\[D^2\] = 1^2 \cdot p_1 + 2^2 \cdot p_2 + 3^2
\cdot p_3 = p_1 + 4p_2 + 9p_3 \in \[1.0, 9.0\]\$\$Для устранения
занижения второго уровня (*Relational*) и формализации поощрения за
исследовательскую инициативу применяется **вогнутая корневая
калибровка** с индикатором постановки встречной проблемы 3-го уровня
\$I\_{\text{init}} \in \\0, 1\\\$ (\$B\_{\text{init}} = 1.0\$):

\$\$S\_{\text{SOLO}} = \min\left(100.0, \\ 100.0 \times
\sqrt{\frac{\mathbb{E}\[D^2\] - 1.0}{8.0}} + B\_{\text{init}} \cdot
I\_{\text{init}}\right)\$\$

- При чистом ответе уровня 1 (\$p_1 = 1.0 \implies \mathbb{E}\[D^2\] =
  1.0\$): \$S\_{\text{SOLO}} = 0.0\$.

- При чистом ответе уровня 2 (\$p_2 = 1.0 \implies \mathbb{E}\[D^2\] =
  4.0\$): \$S\_{\text{SOLO}} = 61.2\$ балла.

- При смешанном профиле \$\mathbf{P}\_{\text{agg}} = \[0.05, 0.15,
  0.80\]\$ (\$\mathbb{E}\[D^2\] = 7.85\$) и проявленной инициативе
  (\$I\_{\text{init}} = 1\$):

> \$\$S\_{\text{SOLO}} = 100.0 \times \sqrt{\frac{7.85 - 1.0}{8.0}} +
> 1.0 = 92.53 + 1.0 \approx \mathbf{93.5}\text{ балла}\$\$

**4.3. Калиброванный коэффициент концептуальной плотности
(\$K\_{\text{density}}\$) и порог уверенности (\$C\_{\text{sample}}\$)**

Для фильтрации «воды» без штрафования развернутых рассуждений и
иностранных студентов используется нормированный коэффициент плотности
концептов (\$\alpha = 3.5\$, мягкий порог \$\kappa\_{\min} = 0.75\$ при
on_topic = True): \$\$K\_{\text{density}} = \begin{cases} \min\left(1.0,
; \max\left(0.75, ; \frac{3.5 \cdot N\_{\text{concepts}}}{\sqrt{\max(1,
N\_{\text{total_tokens}})}}\right)\right), & \text{если }
\text{on_topic} = \text{True} \\ 0.0, & \text{если } \text{on_topic} =
\text{False} \end{cases}\$\$Коэффициент полноты выборки при целевом
числе реплик \$N\_{\text{target}} = 3\$:\$\$C\_{\text{sample}} =
\min\left(1.0, ; \frac{N\_{\text{turns}}}{3}\right)\$\$Итоговый
диагностический индекс глубины познания ИИ:

\$\$S\_{\text{depth}} = \text{round}\left(S\_{\text{SOLO}} \times
K\_{\text{density}} \times C\_{\text{sample}}, \\ 1\right)\$\$

**4.4. Односторонняя положительная ректификация (\$\Delta_i^+\$) и
робастный \$Z\$-score**

Для каждого студента \$i\$, завершившего валидную сессию
(\$N\_{\text{turns}} \ge 2\$), вычисляется сырое отклонение \$\Delta_i =
S\_{\text{depth}, i} - G\_{\text{prof}, i}\$ (используемое для оценки
естественной дисперсии канала оценивания) и **односторонняя
ректифицированная дельта**:

\$\$\Delta_i^+ = \max\left(0.0, \\ S\_{\text{depth}, i} -
G\_{\text{prof}, i}\right)\$\$

- Если \$S\_{\text{depth}, i} \le G\_{\text{prof}, i}\$, то \$\Delta_i^+
  = 0.0\$ и \$Z_i^+ = 0.0\$ — **занижение оценки преподавателя не
  рассматривается ни при каких условиях**.

- По выборке валидных завершенных сессий вычисляются робастная медиана
  \$\text{Median}\_\Delta =
  \text{median}(\mathbf{\Delta}\_{\text{valid}})\$ и медианное
  абсолютное отклонение \$\text{MAD} = \text{median}(\vert\Delta_j -
  \text{Median}\_\Delta\vert)\$ с нижним порогом защиты от деления на
  ноль \$\sigma\_{\text{rob}} = \max(\sigma\_{\min}, 1.4826 \times
  \text{MAD})\$, где \$\sigma\_{\min} = 4.0\$.

- Для всех студентов с положительным расхождением (\$\Delta_i^+ \> 0\$)
  рассчитывается робастный стандартизированный индекс:

> \$\$Z_i^+ = \frac{\Delta_i^+ -
> \text{Median}\_\Delta}{\sigma\_{\text{rob}}}\$\$

\# 3. EXACT MATHEMATICAL SPECIFICATION (\`backend/math_engine.py\`)

canonical student \`stud_aai_042\` produces the exact target metrics:

1\. \*\*Session Validity Gate:\*\*

\- If \`turns_count \< 2\` or \`on_topic == False\`: status is

2\. \*\*Progressive Socratic Turn Aggregation:\*\*

\- Each turn \$t\$ has normalized SOLO probabilities \$\mathbf{P}\_t =
\[p\_{1,t}, p\_{2,t}, p\_{3,t}\]\$ with \$p_1 + p_2 + p_3 = 1\$.

\- For a 3-turn session, aggregate using progressive Socratic weights
\$\mathbf{w} = \[0.0556, 0.1320, 0.8124\]\$:

\$\$\mathbf{P}\_{\text{agg}} = \text{round}\left(\sum\_{t=1}^3 w_t

\$\mathbf{P}\_2 = \[0.00, 0.85, 0.15\]\$, \$\mathbf{P}\_3 = \[0.00,

Score:\*\*

\- \$\mathbb{E}\[D^2\] = 1^2 \cdot p_1 + 2^2 \cdot p_2 + 3^2 \cdot p_3
\in \[1.0, 9.0\]\$.

\- Root-Quadratic Calibration with formalized Socratic Initiative bonus
(\$B\_{\text{init}} = 1.0\$ if \`socratic_initiative == True\` else
\$0.0\$):

\$\$S\_{\text{SOLO}} = \text{round}\left(\min\left(100.0, \\ 100.0
\times \sqrt{\frac{\mathbb{E}\[D^2\] - 1.0}{8.0}} +
B\_{\text{init}}\right), \\ 1\right)\$\$

\- Verify that for \$\mathbb{E}\[D^2\] = 7.85\$ and

4\. \*\*Calibrated Concept Density (\$K\_{\text{density}}\$) & Sample

\- If \`on_topic == False\`, \$K\_{\text{density}} = 0.0\$.
